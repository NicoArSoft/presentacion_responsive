## ⌨️ Atajos de Navegación
- `▶` / `Espacio` / `PageDown`: Avanzar.
- `◀` / `PageUp`: Retroceder.
- `Inicio` (`Home`): Ir a Portada.
- `Fin` (`End`): Ir al Cierre.
- `T`: Activar / Pausar Timer del Expositor en el HUD.
- `J` / `K`: Navegar el Coverflow 3D en la Slide 7.
- `Esc`: Cerrar modales / Lightbox / Simulador.
