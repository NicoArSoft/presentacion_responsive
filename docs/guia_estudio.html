🃏 Tarjetas de Concepto — Preguntate esto antes de ensayar

T1 📱

¿Qué es Responsive Web Design y por qué importa hoy?

Diseño adaptable: que el sitio funcione correctamente en celular, tablet y PC. +60% del tráfico web actual es mobile. Sin responsive = excluir a la mayoría.
T2 🏗

¿Qué es HTML semántico y por qué es mejor que usar solo <div>?

HTML semántico usa etiquetas con significado real: <header>, <main>, <section>, <nav>. El navegador, los lectores de pantalla y Google entienden la estructura. Un <div> no dice nada.
T3 🎨

¿Qué es CSS Flexbox y para qué sirve?

Sistema de maquetación unidimensional (una fila o columna). Perfecto para alinear elementos y distribuir espacio de forma flexible. Esta presentación usa Flexbox en casi todos los layouts.
T4 ⊞

¿Qué es CSS Grid y cuándo usarlo?

Sistema de maquetación bidimensional (filas y columnas simultáneamente). Ideal para galerías, portafolios, layouts de página completa. El collage de esta presentación usa Grid.
T5 🏡

¿Qué es un framework y cómo lo explicás sin jerga técnica?

Un sistema ya preparado para el trabajo web avanzado. La analogía: pasar de una habitación única a una casa organizada por espacios. Cada componente tiene su responsabilidad y puede modificarse sin afectar los demás.
T6 ⚡

¿Qué es Vue.js y qué problema resuelve?

Framework JavaScript para construir interfaces web interactivas con arquitectura de componentes. Resuelve la complejidad de los proyectos grandes: separación de responsabilidades, reutilización, estado reactivo.
P1 🏫

¿Dónde podrías enseñar HTML/CSS en la ETP?

Informática y Programación: primer año de cualquier técnica. Diseño Gráfico: maquetación web como herramienta profesional. Emprendimiento: portafolio como presencia digital laboral.
P2 📚

¿Qué es la transposición didáctica y cómo la aplicaste?

Transformar un saber técnico/experto en un saber enseñable. Lo apliqué creando tutoriales en YouTube que simplifican conceptos complejos del desarrollo web para estudiantes sin experiencia.
P3 🤖

¿Por qué son importantes las bases de HTML/CSS en la era de la IA?

La IA genera código — pero si no entendés las bases, no podés revisar, corregir ni enseñar lo que genera. HTML y CSS son la alfabetización digital del desarrollador web actual.
M1 🎯

¿Por qué elegiste freeCodeCamp y no otra plataforma?

Gratuita, sin fines de lucro, 100% práctica, comunidad global de 100k graduados. El currículo coincide con lo que la industria pide hoy. Y se aprende construyendo, no leyendo.
❓ ⚖

¿Cómo mediste que los alumnos aprendieron? ¿Usaste algún criterio de evaluación?

El criterio principal fue la producción concreta: el portafolio web publicado y funcional. Evaluamos accesibilidad, adaptabilidad y claridad del código. La publicación en la web es la evidencia más directa.
❓ 🔄

¿Qué cambiarías si lo hicieras de nuevo?

Incorporaría desde el inicio más instancias de feedback entre pares. Y arrancaría con Git/GitHub desde la primera clase — porque publicar en la web les abre las puertas al portfolio profesional real.

🎤 Preguntas Posibles del Tribunal — Con Respuestas Sugeridas

¿Por qué HTML y CSS puro, sin usar herramientas más modernas como React o Next.js?
Las bases primero. HTML y CSS son los cimientos de todo lo que existe en la web. React, Next.js, Vue — todos generan HTML y CSS al final. Si un estudiante no entiende las bases, usar un framework es construir sobre arena.

Esta presentación en sí es la demostración: 100% HTML y CSS, sin frameworks, sin librerías. Fondos animados, transiciones, diseño responsive, efectos hover — todo con los estándares básicos de la web.
✦ Clave: señalar la presentación misma como evidencia
¿Qué evidencia tenés de que los alumnos aprendieron realmente y no solo copiaron el tutorial?
La personalización. Cada portafolio tiene datos reales del alumno, sus habilidades, su foto, sus proyectos propios. No son copias — son adaptaciones. La comprensión se evidencia en las decisiones de diseño que cada uno tomó. Y el despliegue en la web real (Netlify) lo confirma.
✦ Clave: mostrar el collage del slide 5 y señalar las diferencias entre cada portafolio
¿Cómo se vincula esto con el diseño curricular de la ETP?
El diseño curricular de la ETP en Mendoza incorpora Informática, Diseño y Comunicación, y Formación para el Trabajo. En los tres hay lugar para el desarrollo web: como herramienta de expresión, como competencia laboral y como contenido técnico específico.

Un portafolio web es simultáneamente un producto técnico, un documento de presentación laboral y una muestra de capacidades cognitivas — algo que el currículum de papel no puede ofrecer.
¿Cómo usaste la plataforma en tu propia práctica docente, más allá de recomendarla?
La usé como modelo de metodología. freeCodeCamp enseña construyendo proyectos paso a paso. Yo repliqué eso en mis tutoriales de YouTube y en las clases presenciales — aprender haciendo, con un producto visible al final de cada sesión. El canal "Nico Code" nació directamente de esa metodología.

💡 Tips para el Día de la Defensa

👁

Contacto visual

Mirá al tribunal, no a la pantalla. La pantalla está detrás de vos para el público. Vos tenés las palabras — ellos tienen el visual.

⏸

Las pausas son tuyas

Una pausa de 2-3 segundos después de una frase importante da más impacto que seguir hablando. Dejá que el mensaje aterrice.

🖱

Mostrar los efectos visuales

Pasá el mouse sobre imágenes para mostrar el zoom. En el certificado, mostrá el efecto 3D. La presentación es parte del contenido técnico.

⌨

Teclas de navegación

Usá las flechas del teclado para navegar. No el mouse. Más profesional y seguro. T activa el cronómetro discreto (solo vos lo ves).

❓

Si no sabés una respuesta

"Eso lo tengo para seguir investigando" es una respuesta válida y honesta. No inventar. El tribunal valora la honestidad académica.
