### Diapositiva 5: Frameworks Modernos y la Analogía del Cuerpo Humano
*(Tono didáctico, pausado y explicativo).*

> "En una segunda etapa, avanzamos hacia el uso de **Frameworks Modernos** (como React, Angular, Svelte o Vue), que son las herramientas estandarizadas que utiliza la industria para crear sistemas modulares.
> 
> Para explicar la diferencia entre la programación básica y el uso de componentes a personas sin perfil técnico, utilizo una analogía muy clara:"
> 
> *(Analogía del cuerpo humano)*
> * "El desarrollo básico tradicional es como una **extremidad rígida sin articulaciones**: todo el código está en una sola pieza. Si queremos modificar un sector, corremos el riesgo de desarmar toda la estructura."
> * "En cambio, trabajar con componentes y frameworks es como **los sistemas y órganos del cuerpo humano**: el corazón, los pulmones o el sistema circulatorio cumplen tareas autónomas y especializadas, pero se comunican y trabajan de forma coordinada. Si necesitamos mejorar un componente, lo hacemos sin comprometer el funcionamiento general."
